Reinforcement Beacons Fixed - v4.4



Requires Bingus Shared Loader loader-v14 or newer / API 1 or newer.

data-v4.4 updates automatic reinforcement anchor recognition for the current game.

Supported: Steam build 25480438 / EXE 1.8.46015.0.



1. Close Helldivers 2.

2. Remove or replace the previous Reinforcement Beacon Fix / Reinforcement

   Beacons Fixed entry in HDArsenal or HD2MM. Use only one manager.

3. Import Reinforcement-Beacons-Fixed-v4.4.zip and Bingus-Shared-Loader-v17.zip.

   The loader is a separate download; managers do not install it automatically.

4. Enable both packages, then Purge and Deploy. Importing alone can leave

   the previous version's archive in the game directory.

5. Launch the game. Check %LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/ReinforcementBeaconsFixed.log for

   data-v4.4 and the correction count.



Use the current module-only Bounce and Hellpod Steering packages if installed.

The renamed packages retain their previous manager GUIDs and Lua resource names.

Do not install renamed and older copies together.



Each diver needs this mod and the loader on their own client. A host-only

installation does not correct an unmodded teammate's reinforcement.



The mod changes only your queued reinforcement X/Y. Solo calls target the

original sampled position; teammate calls target the selected beacon.

Height, countdown and descent remain native. Three prior solo tests confirmed

queue correction. Data-v3's multiplayer repair passes offline tests and still

needs installed verification. A small solo landing offset remains unresolved.



To uninstall, disable this mod and Purge/Deploy. Keep Bingus Shared Loader

enabled for any remaining dependent mods. No executable-memory patch is installed.

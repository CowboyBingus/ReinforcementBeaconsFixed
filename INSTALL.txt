1. Close Helldivers 2.

2. Remove or replace the previous Reinforcement Beacon Fix / Reinforcement

Do not install renamed and older copies together.

installation does not correct an unmodded teammate's reinforcement.

original sampled position; teammate calls target the selected beacon.

queue correction. Data-v3's multiplayer repair passes offline tests and still
